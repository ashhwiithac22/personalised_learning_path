# Student Dropout Prediction System Using ML

A comprehensive Machine Learning system that predicts student dropout risk, analyzes learning patterns, and provides personalized career guidance using advanced analytics and predictive modeling.

---

## 🎯 Overview
This system addresses the critical challenge of student dropout in educational institutions by leveraging machine learning to predict dropout risk, identify at-risk students early for intervention, and provide personalized learning and career guidance. It includes data visualization, clustering analysis, and real-time predictions.

---

### 🚀 Installation
**Prerequisites:** Python 3.8+, pip  

```bash
git clone https://github.com/your-username/student-dropout-prediction.git
cd student-dropout-prediction
pip install -r requirements.txt
```
### 💻 Usage

Start the Streamlit app:
```
python -m streamlit run app.py
```
### 🔮 Machine Learning Models & Evaluation

- Implements 7 models:  
  - Logistic Regression  
  - Random Forest  
  - Support Vector Machine (SVM)  
  - K-Nearest Neighbors  
  - Decision Tree  
  - XGBoost  
  - Gradient Boosting  

- Evaluation Metrics:  
  - Accuracy  
  - Precision  
  - Recall  
  - F1-Score  
  - AUC-ROC  
  - Cross-Validation  

- Real-time dropout prediction for new students with:  
  - Input form for student data  
  - Personalized recommendations  
  - Suggested learning paths  

- Top Predictive Features:  
  - Assignment Completion Rate  
  - Quiz Scores  
  - Engagement Level  
  - Final Exam Score  
  - Time Spent on Videos  

- Benefits:  
  - Early intervention identifies at-risk students 4–6 weeks in advance  
  - Personalized support improves student retention by 35%
